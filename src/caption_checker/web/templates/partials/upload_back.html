How to upload it back

In YouTube Studio: Subtitles → pick the video → ADD LANGUAGE (or ADD under Subtitles) → Upload file → With timing → Continue → choose the file → Save.

Your uploaded captions are kept alongside the original captions and must be published: if they aren't, the auto-captions remain the only live captions.
