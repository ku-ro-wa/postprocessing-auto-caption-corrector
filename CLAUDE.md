# CLAUDE.md

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `ku-ro-wa/postprocessing-auto-caption-corrector`, managed with the `gh` CLI. External PRs are not part of the triage queue. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
